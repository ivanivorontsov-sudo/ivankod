## 1.3.2 (25.10.2026)
- Веб-чаты: все запросы проекта идут в один разговор на сайте; новый чат — только кнопкой «＋ Новый чат», при смене проекта или когда сайт сам закрыл чат. Инструкция отправляется один раз на чат.
- Отправка в веб-чат: страница считается готовой по появлению поля ввода (без ожидания полной загрузки всех файлов сайта и без лишних 2,5 с), подтверждение отправки опросом вместо пауз, зависший индикатор «печатает» больше не держит ответ 90+ с.
- «Понятный»: компактный справочник (служебные слова, правила, встроенные функции, стд/…, три проверенных компилятором примера, частые ошибки), исправления по сообщениям компилятора без ИИ.
- Автоисправление: до 5 попыток ИИ с нужными строками, подсказками и прошлым диффом; проблемы компьютера чинятся сами и попыткой не считаются; Gradle собирает проект с русскими буквами в пути в копии без русских букв.
- Задержки на имитациях сайтов (scripts/websim): до — отправка 4,7 с, ответ 12,8 с (DeepSeek-подобный индикатор — 98 с); после — отправка 0,5–0,9 с, ответ 3,5–4,0 с.

## 1.3.0 (21.10.2026)

### Что нового
- **Простой режим → 📱 Kotlin**: настоящее Android-приложение. Строгая заготовка (Gradle, AGP 8.7.3, Kotlin 2.0.21, SDK 35, без AndroidX), ИИ пишет только тело `class App : Ui` в разделе `===KOTLIN===`. Прогрев Gradle при выборе способа. Ошибки kotlinc — по-русски, с номером строки внутри кода ИИ.
- **Простой режим → 🪟 C# WinForms**: настоящая программа Windows (.NET 8, один самодостаточный EXE, без веба). ИИ пишет только тело `AppForm : UiForm` (`===CSHARP===`). Пробный запуск: окно должно открыться без исключения в Start().
- **Простой режим и режим для опытных → 🇷🇺 «Понятный»**: встроенный компилятор 2.1.0-beta.1 (resources/ponyatny/ponyatny.exe). Проверка `ponyatny проверить` + пробный запуск, НАСТОЯЩАЯ сборка `ponyatny собрать` в EXE. Перевод в Python/JS/C# — только отдельной кнопкой «Перевести в…», к сборке не подключается. Подсветка .pon в редакторе. Полное описание синтаксиса (docs/СИНТАКСИС.md, ветка fix/audit) — в подсказке ИИ.
- **📘 Самоучитель «Понятный»**: 11 уроков (вывод, переменные на кириллице, ввод, условия, циклы, функции, списки/словари, классы, ошибки, модули, прощение опечаток). Объяснение, пример с запуском одним нажатием, задание с автопроверкой настоящим компилятором, прогресс сохраняется.
- Перед сборкой проверяется всё нужное (JDK, Android SDK, Gradle, .NET SDK, компилятор); недостающее ставится кнопкой с проверкой после установки. Находятся и инструменты Android Studio (jbr, %LOCALAPPDATA%\Android\Sdk, Gradle из .gradle\wrapper\dists) и Visual Studio (Program Files\dotnet).
- Не больше 1 автоисправления, сломанную программу не собираем, проблемы компьютера ИИ не отправляем.
- Исправлено: русские буквы, разрезанные между кусками сетевого ответа, превращались в «�» (StringDecoder); бесплатный Pollinations (1 ответ в 30 с): студия выдерживает паузу и один раз повторяет после FREE_LIMIT.
- Подпись: НОВЫЙ самоподписанный сертификат (SHA-256 08:F9:E7:5C:…:D1:1C), он ОТЛИЧАЕТСЯ от сертификата 1.2.0 (тот утерян).
