## Новое в 1.4.0 — декомпиляция

Кнопка **🔓 Декомпилировать** (рядом с «Запустить»): выберите готовую программу — ИванКод восстановит её код и откроет его на «Понятном».

| Что открыть | Чем декомпилируется | Что нужно |
|---|---|---|
| APK, DEX | JADX 1.5.1 | JDK 17 (ставится кнопкой) |
| JAR, .class | CFR 0.152 | JDK 17 |
| .NET exe/dll | ILSpy (ilspycmd 9) | .NET 8 (ставится кнопкой) |
| Python .pyc, exe из PyInstaller | pyinstxtractor → decompyle3/uncompyle6 (pycdc, если есть) | Python 3 |
| Обычные exe/ELF (C/C++) | Ghidra 10.4 headless | по желанию, ~400 МБ |

Перевод в «Понятный» 2.4 идёт по дереву разбора (tree-sitter), не по тексту. В код попадают обычные слова языка, не шуточные синонимы: классы и интерфейсы, перечисления, `switch`/`do…while`, несколько `catch` по типу, `instanceof`/`is`, побитовые операции, целые деления, коллекции и строки (`add`/`size`/`get`/`put`/`contains`/`substring`…), `System.out`/`Console.WriteLine`/`printf` (в том числе простой `%d %s %f`), `System.err`/`fprintf(stderr)` → `предупреди`, `Scanner`/`ReadLine`/`scanf` → `спроси`, `System.exit` → `выход`, C-структуры и `#define` с числом или строкой, вызовы `main` в конце.

Что в «Понятном» нет (goto, указатели, `sizeof`, сеттеры свойств, ссылки на метод `::`, анонимные классы, `switch` как выражение) остаётся комментарием с исходной строкой. Код декомпилятора лежит рядом в папке «исходник».
**Программа никогда не запускается**: её копия только читается декомпиляторами с ограничением времени и приоритета.

Ограничения: имена переменных и структура — как восстановил декомпилятор; Python 3.9+ без pycdc показывается только байткодом; сложные форматы printf (`%x`, ширина поля) переводятся без выравнивания; большие APK переводятся частично (первые 40 файлов кода приложения).
