## Новое в 1.4.0 — декомпиляция

Кнопка **🔓 Декомпилировать** (рядом с «Запустить»): выберите готовую программу — ИванКод восстановит её код и откроет его на «Понятном».

| Что открыть | Чем декомпилируется | Что нужно |
|---|---|---|
| APK, DEX | JADX 1.5.1 | JDK 17 (ставится кнопкой) |
| JAR, .class | CFR 0.152 | JDK 17 |
| .NET exe/dll | ILSpy (ilspycmd 9) | .NET 8 (ставится кнопкой) |
| Python .pyc, exe из PyInstaller | pyinstxtractor → decompyle3/uncompyle6 (pycdc, если есть) | Python 3 |
| Обычные exe/ELF (C/C++) | Ghidra 10.4 headless | по желанию, ~400 МБ |

Перевод в «Понятный» идёт по дереву разбора (tree-sitter), не по тексту; что не переводится (goto, switch, указатели…), остаётся комментарием с исходной строкой. Код декомпилятора лежит рядом в папке «исходник».
**Программа никогда не запускается**: её копия только читается декомпиляторами с ограничением времени и приоритета.

Ограничения: имена переменных и структура — как восстановил декомпилятор; Python 3.9+ без pycdc показывается только байткодом; для C перевод только самый простой (printf-форматы не разбираются); большие APK переводятся частично (первые 40 файлов кода приложения).
